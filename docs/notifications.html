Alerts

Jammonic sends an alert when a check turns DOWN and when it is UP again (with how long it was down). Channels work together; an empty setting turns a channel off.

Telegram

Variable Meaning
MONITOR_TELEGRAM_BOT_TOKEN token of your bot from @BotFather
MONITOR_TELEGRAM_CHAT_ID chat or channel to write to

Email

Variable Meaning
MONITOR_MAIL_TO recipients, comma-separated
MONITOR_MAIL_FROM sender address
MONITOR_SMTP_HOST, MONITOR_SMTP_PORT SMTP server (port 587 by default, STARTTLS)
MONITOR_SMTP_USERNAME, MONITOR_SMTP_PASSWORD SMTP login
MONITOR_MAIL_TYPES only checks of these types, comma-separated — e.g. PUSH for backups and timers; empty — all checks

Webhook

MONITOR_WEBHOOK_URL gets a POST with JSON: event (check, previous and new status, message, times) and text (the same text as in Telegram). With MONITOR_WEBHOOK_SECRET the body is signed: X-Monitor-Signature: sha256=<HMAC-SHA256 of the body> — compare it before trusting the call.
