Jammonic documentation

Jammonic is a self-hosted uptime monitor that is configured by code: every check can be created with one REST call or described in one YAML file, and the web UI shows the same data. One Docker image, a SQLite database in a volume.

What it does

  • Checks: HTTP(S), TCP, TLS certificates and push (heartbeats for backups and cron jobs).
  • Status page: public, grouped, 90 days of uptime, rendered on the server.
  • Alerts: Telegram, email and a signed webhook; a short failure is re-checked before it becomes an alert.
  • API: idempotent create-or-update by your own key, errors as Problem Details (RFC 9457).

Where to start

  • Try it on your computer — one docker run.
  • Install on a server — Docker Compose and HTTPS.
  • Checks — every field of every check type.
  • API and configuration file — monitoring as code.
  • Alerts, status page, sign-in.
